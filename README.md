<h2>
  <span style="font-size: 1.4em;">🌟</span>
  <span class="glow-text"> About This Project</span>
</h2>

<div class="cosmic-card">
  <p style="color: #c8d6e5; font-size: 1.05em; line-height: 1.7;">
    <strong class="glow-text">Sky AI WhatsApp Agent</strong> adalah sebuah bot pintar yang menghubungkan 
    <strong class="purple-text">Gemini AI</strong> langsung ke akun WhatsApp Anda. 
    Cukup kirim pesan dengan trigger <code style="background: rgba(0,212,255,0.1); padding: 2px 8px; border-radius: 4px; color: #00d4ff;">/chat</code>, 
    dan bot akan merespon dengan jawaban cerdas dari AI.
  </p>
  <p style="color: #c8d6e5; font-size: 1.05em; line-height: 1.7;">
    Dibangun dengan <strong class="green-text">Baileys</strong> (library WhatsApp Web terbaik untuk Node.js) 
    dan menggunakan sistem <strong style="color: #fbbf24;">Pairing Code</strong> — 
    tidak perlu scan QR code rumit!
  </p>
</div>

<br>

<h2>
  <span style="font-size: 1.4em;">✨</span>
  <span class="gold-text"> Key Features</span>
</h2>

<div class="cosmic-card">

<!-- Gold Animated Checkmarks -->
<p>✅ &nbsp; <strong class="glow-text">Pairing Code WhatsApp</strong> — <span style="color: #c8d6e5;">Hubungkan bot tanpa QR code, cukup masukkan kode 8 digit</span></p>
<p>✅ &nbsp; <strong class="glow-text">Gemini AI Integration</strong> — <span style="color: #c8d6e5;">Respons cerdas dari REST API Gemini</span></p>
<p>✅ &nbsp; <strong class="glow-text">Session Persistence</strong> — <span style="color: #c8d6e5;">Tidak perlu pairing ulang setiap restart</span></p>
<p>✅ &nbsp; <strong class="glow-text">Multi-Platform</strong> — <span style="color: #c8d6e5;">Berjalan di Termux (Android), Ubuntu, Kali Linux</span></p>
<p>✅ &nbsp; <strong class="glow-text">Auto-Reconnect</strong> — <span style="color: #c8d6e5;">Koneksi otomatis pulih jika terputus</span></p>
<p>✅ &nbsp; <strong class="glow-text">Typing Indicator</strong> — <span style="color: #c8d6e5;">Menampilkan status "mengetik..." saat memproses AI</span></p>
<p>✅ &nbsp; <strong class="glow-text">Long Message Support</strong> — <span style="color: #c8d6e5;">Pesan panjang otomatis dipecah menjadi beberapa bagian</span></p>
<p>✅ &nbsp; <strong class="glow-text">Detailed Logging</strong> — <span style="color: #c8d6e5;">Semua chat dan response tercatat di file log</span></p>
<p>✅ &nbsp; <strong class="glow-text">Multiple Triggers</strong> — <span style="color: #c8d6e5;">Gunakan /chat, /ai, atau /ask untuk memanggil AI</span></p>
